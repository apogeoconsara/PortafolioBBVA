# Archived: Clara Growth & Lifecycle Agent demo (13 synthetic companies)

Copied unchanged from `apogeoconsara/portafolioclara` at commit `57edf3f` (also kept there on the branch
`archive/demo-13-empresas`). It is stored here only so it can be picked up again later.

- It is **not published** by this repository's Netlify site (that site publishes the root `public/` and
  `netlify/functions/` only).
- To run it again, deploy this folder as its own Netlify site (`clara-demo-13-empresas/` as the base directory) and set the
  variables listed in its `.env.example`. Leave `CUSTOMERIO_SEND_ENABLED` unset so no email can be sent.
- All 13 companies are synthetic.
